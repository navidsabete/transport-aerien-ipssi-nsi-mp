--- Note methodologique ---
Une premiere estimation faite en dehors de MongoDB (script Node.js lisant les fichiers
sources bruts) donnait des chiffres legerement differents (403/410/742 au lieu de
360/370/659), a cause d'un bug de parsing CSV artisanal (mauvaise gestion d'un cas de
guillemets dans les noms d'aeroport). Les chiffres retenus dans le rapport sont ceux
produits par les requetes MongoDB ci-dessus, verifies une seconde fois par un parcours
JS independant (db.routes.find + Set des iata), qui donne exactement les memes valeurs.
Lecon : ne jamais publier un chiffre sans l'avoir fait sortir de la base elle-meme.
