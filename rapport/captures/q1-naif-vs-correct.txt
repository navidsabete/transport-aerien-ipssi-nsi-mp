Contexte : le pipeline naif (route API /agg/q1, api/main.py) ne filtre pas les 0,98 % de
routes vers un aeroport fantome (chapitre ii du rapport). Un second pipeline, correct,
insere un $lookup + $match avant le $group pour ne compter que des destinations reellement
presentes dans airports.

=== NAIF (pipeline actuel de /agg/q1) ===
db.routes.aggregate([
  { $group: { _id: "$src_airport", destinations: { $addToSet: "$dst_airport" } } },
  { $project: { _id: 0, iata: "$_id", n: { $size: "$destinations" } } },
  { $sort: { n: -1, iata: 1 } },
  { $limit: 10 }
])

=== CORRECT (exclut les destinations vers un aeroport inexistant) ===
db.routes.aggregate([
  { $lookup: { from: "airports", localField: "dst_airport", foreignField: "iata", as: "dst" } },
  { $match: { dst: { $ne: [] } } },
  { $group: { _id: "$src_airport", destinations: { $addToSet: "$dst_airport" } } },
  { $project: { _id: 0, iata: "$_id", n: { $size: "$destinations" } } },
  { $sort: { n: -1, iata: 1 } },
  { $limit: 10 }
])
